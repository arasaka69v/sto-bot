# Документация API Росско

В папке `rossko/` лежат официальные описания методов API Росско (WSDL, версия 2.1).
Они скачаны с сервера `https://api.rossko.ru/service/v2.1/<Метод>?wsdl`.
По ним сделан клиент `stobot/suppliers/rossko.py`.

| Метод | Что делает | Где используется |
|---|---|---|
| GetSearch | Поиск по артикулу: цены по складам, наличие, срок, кратность, аналоги (crosses) | поиск, аналоги, перепроверка перед заказом |
| GetCheckout | Оформление заказа | кнопка «Подтвердить заказ» |
| GetCheckoutDetails | Способы доставки и оплаты, адреса, юрлица аккаунта | rossko_setup.bat, проверка ключей при запуске |
| GetOrders | Заказы и даты доставки | /orders |
| GetDeliveryDetails | Графики доставки | пока не используется |

## Чего в API нет

- **Подбора по VIN** нет: для поиска по VIN без артикула нужен отдельный каталог.
- **Корзины кабинета** нет, поэтому корзина живёт в боте.
- **Признаков «оригинал» и «акция»** нет: бот их для Росско не показывает.
- **Расшифровки кодов статусов** нет: бот показывает дату доставки, если Росско её назначил.

## Что стоит проверить на первом реальном запуске

- `delivery` в GetSearch бот считает сроком в днях. Сверьте с личным кабинетом.
- `delivery_parts` в GetCheckout: смысл поля уточните у менеджера. По умолчанию `false`.
- Юрлицо: в `requisite_id` бот передаёт id компании из GetCheckoutDetails.

# 🔧 СТО-бот: заказ запчастей через Telegram

Telegram-бот для автосервиса. Мастера ищут запчасти по артикулу или по названию
и складывают их в общую корзину. Ответственный (админ) проверяет корзину
и подтверждает заказ поставщику.

> **Без ключей Росско бот работает на тестовых данных** (mock). Когда менеджер Росско
> выдаст ключи API, запустите `rossko_setup.bat` — и бот начнёт искать по-настоящему
> (см. [раздел про Росско](#-подключение-настоящего-росско)).

---

## Что умеет

| Функция | Как пользоваться |
|---|---|
| Поиск по артикулу | Просто пришлите артикул: `04465-33471` (или `/search 04465-33471`) |
| Аналоги | Кнопка «🔁 Показать аналоги» под результатами |
| Самый выгодный | ⭐ — самый дешёвый вариант в наличии с доставкой до 3 дней |
| Акции | 🔥 — только если акцию прислал поставщик (бот их не придумывает) |
| Поиск по названию | `граната`, `калодки перед`, `подушка двигла` — бот поймёт, что за деталь (подбор артикула — после подключения каталога по VIN) |
| Машина | Просто пришлите **VIN** — бот сам определит марку, дальше всё привязывается к этой машине. Номер и модель не нужны |
| Корзина | `/cart` — общая для всех: ➖ ➕ 🗑 |
| Заказ | Кнопка «✅ Оформить заказ» (только админ) → проверка цен → «Подтвердить» |
| История | `/orders`, или текстом: «что заказывали для» + VIN или госномер |

## ⚡ Самый простой способ (Windows)

1. Создайте бота в @BotFather и узнайте свой ID в @userinfobot (шаги 3–4 ниже).
2. Дважды кликните **`install.bat`**. Он сам удалит старую установку, поставит библиотеки
   и откроет Блокнот с настройками. Впишите токен и свой ID, нажмите Ctrl+S.
3. Есть ключи Росско? Дважды кликните **`rossko_setup.bat`**: он всё настроит сам
   (см. [раздел про Росско](#-подключение-настоящего-росско)). Нет ключей — бот работает
   на тестовых данных.
4. Дважды кликните **`start.bat`**. Бот запущен, пока открыто чёрное окно.

Что-то сломалось — просто запустите `install.bat` ещё раз. Ваш файл `.env` он не трогает.

> **Положите папку бота поближе к корню диска, например `C:\sto-bot`.** Из глубоких папок вроде
> «Загрузки» с длинными именами установка падает: у Windows лимит 260 символов на путь к файлу.

## 🚀 Установка и запуск (пошагово)

### Шаг 1. Установите Python 3.11 или новее

**Windows:**
1. Откройте https://www.python.org/downloads/ и скачайте последнюю версию.
2. При установке **обязательно поставьте галочку «Add Python to PATH»**.
3. Проверьте: откройте «Командную строку» (Win+R → `cmd`) и выполните:
   ```
   python --version
   ```
   Должно показать `Python 3.11` или выше.

**macOS:** установите с https://www.python.org/downloads/ или через Homebrew:
`brew install python`. Проверка: `python3 --version`.

**Linux (Ubuntu):** `sudo apt install python3 python3-venv python3-pip`.

> Ниже в командах для Windows пишите `python`, для macOS/Linux — `python3`.

### Шаг 2. Скачайте проект и установите зависимости

```bash
git clone https://github.com/arasaka69v/sto-bot.git
cd sto-bot
```

Создайте «виртуальное окружение» — отдельную папку с библиотеками именно для
этого проекта (чтобы не мешать другим программам):

**Windows:**
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

После `activate` в начале строки появится `(.venv)` — значит, всё правильно.
**Каждый раз перед запуском бота** снова выполняйте команду `activate`.

### Шаг 3. Создайте бота в @BotFather

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Start».
2. Отправьте `/newbot`.
3. Введите имя бота, например `СТО Запчасти`.
4. Введите username — латиницей и обязательно с `bot` на конце, например `sto_parts_astana_bot`.
5. BotFather пришлёт **токен** вида `7123456789:AAH...`. Это пароль от бота —
   **никому его не показывайте**.

### Шаг 4. Узнайте Telegram ID свой и мастеров

1. Найдите в Telegram **@userinfobot** и нажмите «Start».
2. Он пришлёт ваш `Id: 123456789` — это и есть Telegram ID.
3. Мастера делают то же самое и присылают вам свои ID.

> Подсказка: если человек, которого нет в списке, напишет вашему боту,
> бот ответит ему «нет доступа» и покажет его ID. Его можно сразу скопировать.

### Шаг 5. Заполните настройки `.env`

Скопируйте шаблон:

- Windows: `copy .env.example .env`
- macOS/Linux: `cp .env.example .env`

Откройте `.env` в любом текстовом редакторе (Блокнот, VS Code) и заполните:

```ini
TELEGRAM_BOT_TOKEN=7123456789:AAH...ваш токен
ADMIN_IDS=123456789                 # ваш ID (несколько — через запятую)
MASTER_IDS=111111111,222222222      # ID мастеров через запятую
SUPPLIER=mock                       # пока тестовые данные
TEST_MODE=true                      # заказы никуда не уходят
```

Остальное можно не трогать. Файл `.env` **не попадает в git**: секреты остаются только у вас.

### Шаг 6. Запустите

```bash
python main.py
```

Увидите `✅ Бот запущен`. Откройте своего бота в Telegram и нажмите «Start».
Остановить бота: `Ctrl+C`.

Если в `.env` ошибка, бот так и скажет: например,
`❌ Ошибка в настройках: Не указан TELEGRAM_BOT_TOKEN`.

## ✅ Как проверить всё вручную в Telegram

Тестовые артикулы (mock-данные):

| Артикул | Что там |
|---|---|
| `04465-33471` | Колодки Toyota: оригинал с двух складов + 6 аналогов (есть акция TRW) |
| `90915-YZZE1` | Масляный фильтр: оригинал + аналоги (акция VIC «3 по цене 2») |
| `17801-31120` | Воздушный фильтр с акцией 🔥 |
| `12361-28220` | Опора двигателя |
| `43470-09J60` | ШРУС: оригинала нет в наличии, аналоги есть |
| `OFFLINE-000` | Имитация «поставщик не отвечает» |
| `XX-000-1` | «Ничего не найдено» |

**Сценарий проверки:**

1. Пришлите VIN `JTNB11HK103456789` → «Машина выбрана по VIN: Toyota». Больше ничего не спросит.
2. Пришлите `04465-33471` → два оригинала Toyota с разных складов, ⭐ у самого выгодного (дешевле — тот, что из Алматы, но его везти 4 дня).
3. Нажмите «🔁 Показать аналоги» → оригинал и аналоги рядом, 🔥 у акционных.
4. Нажмите «🛒 В корзину» у TRW и у NIBK (у NIBK два раза).
5. Пришлите `90915-YZZE1` → аналоги → добавьте VIC.
6. `/cart` → видно, кто добавил, для какой машины, итог. Попробуйте ➖ ➕ 🗑.
7. Нажмите «✅ Оформить заказ» (видно только админу). Бот перепроверит цены, и вы увидите:
   - 📈 TRW подорожал (21 900 → 23 500);
   - ⚠️ NIBK: осталась 1 шт, закажем 1;
   - ❌ VIC закончился и не будет заказан.
8. «Подтвердить» → в тестовом режиме бот покажет, **что бы он отправил**, а корзина не изменится.
9. Поставьте `TEST_MODE=false`, перезапустите бота и повторите шаг 7–8. Придёт
   номер заказа `MOCK-...`, корзина очистится, а VIC (его нет в наличии) останется в ней.
10. `/orders` → заказ со статусом. Через пару минут статус в mock «поменяется».
11. Напишите `что заказывали для JTNB11HK103456789`.
12. Поиск по названию: `граната`, `калодки перед`. Бот поймёт деталь, но пока **ничего не
    спрашивает и честно просит артикул**: подобрать артикул по VIN без каталога нельзя,
    а **придумывать артикулы бот не будет никогда**.

    Когда подключим каталог по VIN, будет так: VIN → «колодки перед» → сразу цены.
    Бот будет спрашивать только то, чего VIN не знает (сторону, ось), одним сообщением
    с кнопками. Двигатель и КПП каталог берёт из VIN.
13. Попросите мастера (или второй аккаунт) написать боту: ему придёт уведомление о заказе,
    а админу — о каждом добавлении в корзину.

## 🔁 Подключение настоящего Росско

Клиент Росско готов. Он написан строго по официальным описаниям методов
с сервера Росско (лежат в `docs/rossko/`, подробности — в `docs/README.md`).

1. Попросите у менеджера Росско **ключи API: KEY1 и KEY2** для вашего бизнес-аккаунта.
2. Дважды кликните **`rossko_setup.bat`**:
   - вставьте KEY1 и KEY2;
   - бот сам спросит у Росско ваши способы доставки, адреса и способы оплаты
     и предложит выбрать номером (если вариант один, выберет сам);
   - впишите имя и телефон для заказов;
   - бот сделает пробный поиск и сам запишет всё в `.env`.
3. Запустите `start.bat`. В окне появится «✅ Росско: ключи приняты».
4. Сначала проверьте всё в **тестовом режиме** (`TEST_MODE=true`): поиск, цены и наличие
   будут настоящие, а заказ не уйдёт, бот только покажет, что отправил бы.
5. Когда всё сходится, поставьте в `.env` `TEST_MODE=false` и перезапустите бота.

**Что умеет API Росско и как это видно в боте:**
- цены по вашему аккаунту, наличие и срок по каждому складу;
- аналоги (если самой детали нет в наличии, бот сразу показывает аналоги);
- кратность («продаётся по 2 шт»): кнопки ➕ ➖ сами меняют количество на 2;
- примечания склада (ℹ️) — показываются как есть;
- заказ; если Росско примет только часть позиций, остальные останутся в корзине с причиной;
- дата доставки в /orders, когда Росско её назначит.

**Чего у Росско в API нет:** подбора по VIN, корзины кабинета (корзина живёт в боте),
признаков «оригинал» и «акция» (бот их не выдумывает).

Вернуться на тестовые данные: `SUPPLIER=mock` в `.env`.

## 🤖 ИИ для распознавания названий (необязательно)

Без ключа бот понимает названия деталей по встроенному словарю
(`stobot/core/parts.py`), и опечатки тоже. Если словарь не справился,
а в `.env` указан `ANTHROPIC_API_KEY`, бот спросит ИИ (Claude).

- ИИ выбирает **только тип детали из справочника**. Ответ ограничен схемой,
  поэтому вернуть артикул ИИ не может.
- Модель: `AI_MODEL=claude-opus-5-5`. Включена серверная подстраховка:
  если модель откажется отвечать, запрос автоматически повторит другая модель.
- Ключ: https://console.anthropic.com → API Keys.

## 💡 Ключевые решения

- **Логика отдельно от Telegram.** `core/` возвращает «текст + кнопки», а адаптер
  рисует их в Telegram. Для WhatsApp Business нужно написать только `adapters/whatsapp/`.
- **Поставщик и каталог — через интерфейсы** (`suppliers/base.py`, `catalog/base.py`).
  Новый поставщик = новый класс с теми же методами.
- **Деньги в `Decimal`, а не `float`:** у `float` бывают ошибки округления (0.1 + 0.2 ≠ 0.3).
- **Защита заказа:** перед заказом цены перепроверяются; если корзину изменили после проверки,
  заказ не уйдёт; двойное нажатие «Подтвердить» не создаст два заказа.
- **Из корзины после заказа удаляется только заказанное.** То, чего не было в наличии,
  остаётся, чтобы не потерялось.
- **Машина — это VIN.** Госномер и модель необязательны. Марку бот определяет по первым
  символам VIN (стандарт ISO 3780); модель и двигатель по VIN узнаёт только каталог.
- **Без каталога — без лишних вопросов.** Уточнения (сторона, ось) имеют смысл, только когда
  есть каталог, который по ним подберёт артикул. Пока его нет, бот их не задаёт.
- **SQLite** — один файл, сервер не нужен; переносится на VPS простым копированием.

## 🖥 Перенос на VPS (потом)

Бот работает через polling, поэтому ни домен, ни HTTPS не нужны. На сервере
(Ubuntu) повторите шаги 1–2 и 5. Чтобы бот работал постоянно и сам
перезапускался, создайте `/etc/systemd/system/sto-bot.service`:

```ini
[Unit]
Description=STO bot
After=network-online.target

[Service]
WorkingDirectory=/home/USER/sto-bot
ExecStart=/home/USER/sto-bot/.venv/bin/python main.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем: `sudo systemctl enable --now sto-bot`. Логи — в `data/logs/bot.log`.
Чтобы перенести историю, скопируйте `data/sto_bot.db`.
